# Гайд 2. Делаем сайт и публикуем его в интернете

**Что делаем:** в Claude Desktop создаём сайт и выкладываем его на GitHub Pages.
**Сколько займёт:** 30–40 минут.
**Что в результате:** ваш сайт открывается по адресу вида `https://ваш-логин.github.io/my-first-site/`.

> 💡 **Главная мысль гайда.** Почти всё за вас делает Claude — нажатиями в окне приложения. Терминал не нужен. Ваша работа — открыть нужную папку, попросить словами «сделай так», нажать «Accept» и пару раз сходить в браузер.

> 🧭 **Условные обозначения:**
> - **🤖** — это делает Claude сам, вы только подтверждаете кнопкой.
> - **👤** — это делаете вы руками (потому что Claude не может — например, нет доступа в Settings GitHub).

---

## Шаг 1. 👤 Создаём папку для проекта

Перед запуском Claude нужно подготовить пустую папку — там будет жить наш сайт.

**Если Windows:**

1. Откройте **Проводник**.
2. Слева выберите **Этот компьютер → Документы** (или любое другое удобное место).
3. Правой кнопкой по пустому месту → **Создать** → **Папку**.
4. Назовите её `my-first-site` (важно: латиницей, без пробелов).

**Если Mac:**

1. Откройте **Finder**.
2. Слева — **Документы**.
3. Правой кнопкой → **Новая папка**.
4. Назовите её `my-first-site`.

---

## Шаг 2. 👤 Открываем папку в Claude Desktop

1. Откройте Claude Desktop, перейдите на вкладку **Code**.
2. Слева вверху нажмите **+ New session** (или используйте уже открытую сессию).
3. В строке настроек сессии (над полем ввода) увидите параметры:
   - **Environment**: оставьте **Local** (значит, работаем на этом компьютере).
   - **Project folder**: нажмите и выберите вашу только что созданную папку `my-first-site`.
   - **Permission mode**: поставьте **Ask permissions** (это безопасный режим — Claude будет спрашивать разрешение перед каждым действием).
4. Внизу — поле ввода. Это место, куда пишем задачи.

> 💡 **Про режим Ask permissions.** Это нормально, что Claude каждый раз спрашивает «можно ли создать файл», «можно ли запустить команду». Соглашайтесь кнопкой **Accept** или нажатием Enter. После того как привыкнете — можете переключиться в **Auto accept edits**, тогда он не будет спрашивать про правки файлов.

---

## Шаг 3. 🤖 Просим Claude сделать сайт

В поле ввода вставьте этот текст (можно поправить под себя):

```
Сделай простой одностраничный сайт-визитку из трёх файлов:
index.html, styles.css, script.js.

На странице должны быть секции:
1. Шапка с моим именем и заголовком "Frontend-разработчик"
2. Обо мне — 2-3 абзаца текста-заглушки
3. Навыки — список из 5-6 пунктов
4. Контакты — email и пара ссылок на соцсети

Дизайн: минималистичный, светлая тема, обычный системный шрифт,
центральная колонка шириной до 800 пикселей. Чтобы нормально
смотрелось и на телефоне.
```

Нажмите **Enter**.

**Что произойдёт:**
- Claude напишет план: какие файлы создаст, что в них будет.
- Перед созданием каждого файла появится окно с диффом (показывает содержимое будущего файла) и кнопками **Accept** / **Reject**.
- Нажимайте **Accept** или Enter — соглашайтесь.
- Через минуту в папке `my-first-site` появятся три файла.

---

## Шаг 4. 🤖 Смотрим результат в Preview-панели

Claude Desktop умеет показывать сайты прямо внутри себя — не надо открывать браузер.

Напишите Claude:

```
Открой index.html в preview-панели, чтобы я мог посмотреть результат.
```

Откроется встроенная панель с вашим сайтом — справа или снизу от чата (можно перетащить за заголовок панели в удобное место).

> 💡 **Хочется в обычном браузере?** Кликните в чате правой кнопкой по `index.html` → **Show in Finder** (Mac) / **Show in Explorer** (Windows). Откроется папка, дальше — двойной клик по `index.html`, и сайт откроется в вашем браузере.

### Хочется что-то поменять?

Просто скажите словами:

> «Сделай шапку темнее, с белым текстом»

> «Добавь иконки рядом с ссылками на соцсети»

> «Замени шрифт на Inter с Google Fonts»

Claude покажет дифф (что собирается изменить) — Accept — Preview обновится автоматически.

Повторяйте, пока не понравится. Это нормально — обычно так и работают: маленькая правка → посмотрел → ещё правка.

## Шаг 5. 👤 Создаём репозиторий на GitHub

Репозиторий — это «папка вашего проекта» на GitHub.

1. Откройте https://github.com (войдите, если ещё не вошли).
2. Сверху справа нажмите **+** → **New repository**.
3. **Repository name:** напечатайте `my-first-site` (точно так же, как локальная папка).
4. **Description:** можно оставить пустым.
5. Внизу выберите **Public** (обязательно — для бесплатного GitHub Pages).
6. **НЕ ставьте** галочки `Add a README`, `Add .gitignore`, `Add a license` — мы добавим всё локально.
7. Нажмите зелёную кнопку **Create repository**.

Откроется страница с инструкциями. Сверху на ней есть строка с адресом репозитория:

```
https://github.com/ВАШ-ЛОГИН/my-first-site.git
```

**Скопируйте этот адрес** — он понадобится через минуту.

---

## Шаг 6. 🤖 Просим Claude загрузить файлы на GitHub

Вернитесь в Claude Desktop. В поле ввода напишите (вставив свой скопированный адрес):

```
Подключи эту папку к моему репозиторию на GitHub
https://github.com/ВАШ-ЛОГИН/my-first-site.git
Сделай первый коммит со всеми файлами и отправь на GitHub в ветку main.
```

**Что сделает Claude:**

- Превратит папку в Git-репозиторий.
- Запишет все файлы в коммит с сообщением.
- Подключит ваш репозиторий на GitHub как удалённый.
- Отправит всё на GitHub.

Перед каждой командой Claude покажет её и спросит подтверждение — нажимайте **Accept**.

### 👤 На этом шаге понадобится войти в GitHub из приложения

Когда Claude дойдёт до команды отправки на GitHub, появится окно с просьбой войти. Здесь два варианта:

#### Вариант А (проще): подключить GitHub через коннектор

1. Рядом с полем ввода в Claude Desktop есть кнопка **+**.
2. Нажмите её → **Connectors** → найдите **GitHub** → **Connect**.
3. Откроется браузер с просьбой авторизоваться. Нажмите **Authorize**.
4. Вернитесь в Claude — теперь он умеет работать с GitHub от вашего имени.
5. Скажите Claude: «продолжи push на GitHub».

#### Вариант Б: через токен

1. Откройте https://github.com/settings/tokens
2. Нажмите **Generate new token** → **Generate new token (classic)**.
3. **Note:** напишите что угодно, например `claude-desktop`.
4. **Expiration:** выберите 90 дней.
5. **Select scopes:** поставьте галочку **repo**.
6. Внизу нажмите **Generate token**.
7. Появится длинная строка вида `ghp_AbC123...`. **Скопируйте её сразу** — второй раз GitHub её не покажет.
8. Вернитесь в Claude Desktop. Когда там просят «Password» — вставьте этот токен (правый клик → Paste, или Cmd+V / Ctrl+V).

**Проверка:** обновите страницу репозитория на GitHub в браузере — там должны появиться ваши файлы (`index.html`, `styles.css`, `script.js`).

## Шаг 7. 👤 Включаем GitHub Pages

Это нужно сделать на сайте GitHub в браузере. Claude не может зайти в настройки вашего репозитория сам — это вы делаете руками.

1. Откройте свой репозиторий: `https://github.com/ВАШ-ЛОГИН/my-first-site`
2. Сверху, среди вкладок, нажмите **Settings** (значок шестерёнки справа).
3. Слева в меню — раздел **Pages**.
4. В блоке **Build and deployment**:
   - **Source:** выберите **Deploy from a branch**.
   - **Branch:** выберите **main**, папку оставьте **/ (root)**.
5. Нажмите **Save**.

Появится сообщение «Your site is live at...» — но не сразу. Подождите 1–3 минуты.

**Проверка:** через пару минут обновите страницу Settings → Pages. Сверху появится зелёная плашка с адресом:

```
https://ВАШ-ЛОГИН.github.io/my-first-site/
```

Откройте этот адрес в браузере — должен загрузиться ваш сайт.

> ⚠️ **Если 404** — подождите ещё 5 минут. Первая публикация иногда занимает до 10 минут. Если 404 держится дольше — на странице репозитория вкладка **Actions** покажет, идёт ли сборка или есть ошибка.

---

## Шаг 8. 🤖 Как менять сайт дальше

Когда захотите что-то поправить:

1. Откройте Claude Desktop, вкладку **Code**.
2. Если сессия закрылась — создайте новую и снова выберите папку `my-first-site` как Project folder.
3. Скажите словами, что хотите изменить:

> «Добавь четвёртую секцию — отзывы клиентов, три карточки в ряд»

4. После того как понравится — попросите выложить:

```
Сохрани изменения в git и отправь на GitHub.
```

Через 1–2 минуты обновите страницу сайта в браузере — увидите изменения.

> 💡 Если в браузере всё ещё старая версия — сделайте **жёсткое обновление страницы**: `Ctrl+Shift+R` на Windows или `Cmd+Shift+R` на Mac. Это сбросит кэш.

## Полезные приёмы в Claude Desktop

### Режимы разрешений (переключаются у строки ввода)

| Режим                  | Когда использовать                                                                                              |
|------------------------|-----------------------------------------------------------------------------------------------------------------|
| **Ask permissions**    | По умолчанию для новичков. Спрашивает перед каждой правкой и каждой командой.                                   |
| **Auto accept edits**  | Когда уже привыкли. Сам соглашается на правки файлов, но всё равно спрашивает перед запуском команд (важно!).   |
| **Plan mode**          | Хотите сначала обсудить план, прежде чем что-то менять. Полезно для сложных задач.                              |

Переключиться можно прямо во время сессии — кнопкой рядом с полем ввода.

### Полезные горячие клавиши

| Что хочу                 | Mac           | Windows         |
|--------------------------|---------------|-----------------|
| Открыть Preview          | Cmd+Shift+P   | Ctrl+Shift+P    |
| Открыть диффы            | Cmd+Shift+D   | Ctrl+Shift+D    |
| Остановить ответ Claude  | Esc           | Esc             |
| Новая сессия             | Cmd+N         | Ctrl+N          |
| Все шорткаты             | Cmd+/         | Ctrl+/          |

### Что говорить Claude (примеры фраз)

| Хочу...                           | Скажите...                                                              |
|-----------------------------------|-------------------------------------------------------------------------|
| Изменить дизайн                   | «Поменяй цвет шапки на тёмно-синий»                                     |
| Добавить новую секцию             | «Добавь секцию с проектами — три карточки с картинками»                 |
| Исправить ошибку                  | «В консоли ошибка: [вставьте текст]. Исправь.»                          |
| Загрузить изменения               | «Сохрани изменения в git и отправь на GitHub»                           |
| Понять, что произошло             | «Объясни, что ты только что сделал»                                     |
| Откатить изменения                | «Откати последний коммит»                                               |
| Показать сайт                     | «Открой index.html в preview-панели»                                    |

## Если что-то не получилось

| Проблема                                            | Что делать                                                                                                                                  |
|-----------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| Claude просит платный аккаунт при работе с Code     | Вернитесь к **Гайду 1, Шаг 1** — нужна активная подписка Pro.                                                                                |
| Push на GitHub выдаёт «Authentication failed»       | Используйте GitHub-коннектор (Шаг 6, Вариант А) либо токен (Шаг 6, Вариант Б).                                                              |
| Push выдаёт «Permission denied»                     | Скажите Claude: «поменяй remote URL на HTTPS». Он сам исправит.                                                                              |
| Сайт открылся, но без стилей (голый текст)          | Скажите Claude: «в index.html замени все пути к CSS и JS на относительные, без слэша в начале». Потом «сохрани и запушь».                   |
| 404 на сайте дольше 10 минут                        | Перепроверьте Settings → Pages: Source = **Deploy from a branch**, Branch = **main**, папка = **/ (root)**.                                  |
| После git push сайт не обновляется                  | Подождите 2 минуты + `Ctrl+Shift+R` / `Cmd+Shift+R` в браузере.                                                                              |
| Claude завис, не отвечает                           | Нажмите **Esc** — это остановит текущее действие.                                                                                            |
| Случайно закрыл Claude Desktop                      | Откройте заново → вкладка **Code** → ваша сессия должна остаться в боковой панели слева. Кликните на неё, чтобы продолжить.                  |
| Хочу начать всё заново                              | Удалите папку `my-first-site` и репозиторий на GitHub (Settings репозитория → Danger Zone → Delete). Начните с Шага 1.                       |
