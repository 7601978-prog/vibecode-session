# Гайд 1. Готовим компьютер к работе

**Что делаем:** ставим Claude Desktop и заводим аккаунт на GitHub.
**Сколько займёт:** 15–25 минут.
**Что в результате:** на компьютере стоит приложение, в котором мы сделаем сайт. После этого — Гайд 2.

> 💡 **Что такое Claude Desktop.** Это обычное приложение — как Telegram или браузер. Скачали, установили, открыли. Внутри есть AI-помощник, который умеет сам создавать файлы, писать код, отправлять проекты на GitHub. Терминал почти не нужен — почти всё через окно приложения.

---

## Шаг 1. Создаём аккаунт Anthropic

Это аккаунт, от которого работает Claude.

1. Откройте в браузере: https://claude.ai
2. Нажмите **Sign up**.
3. Введите email и пароль (или войдите через Google).
4. Откройте почту — там письмо со ссылкой. Кликните по ней.

### Оплачиваем подписку

Без подписки Claude Code работать не будет. Самая дешёвая называется **Pro**, 20 долларов в месяц.

1. На claude.ai нажмите на свой аватар (правый нижний угол).
2. Выберите **Upgrade plan** или **Settings → Billing**.
3. Выберите **Pro**, введите данные карты.

> 💳 **Если карта не принимается:** российские карты обычно не работают. Нужна карта банка из США, Европы, Казахстана или виртуальная карта (например, от казахстанских банков). Это самый частый ступор — лучше решите этот вопрос заранее.

---

## Шаг 2. Скачиваем и устанавливаем Claude Desktop

1. Откройте: https://claude.com/download
2. Сайт сам определит вашу систему (Windows или Mac) и предложит правильный файл.
3. **Если Windows:** скачается `.exe` файл. Запустите его двойным кликом, нажимайте Next, в конце — Install.
4. **Если Mac:** скачается `.dmg` файл. Откройте его, перетащите иконку Claude в папку Applications.

После установки запустите приложение:

- **Windows:** нажмите кнопку Win → начните печатать `Claude` → откройте.
- **Mac:** нажмите Cmd+Space → напечатайте `Claude` → откройте.

При первом запуске войдите в свой аккаунт Anthropic (тот, что создали в Шаге 1).

---

## Шаг 3. Создаём аккаунт GitHub

GitHub — это место, где будет жить ваш сайт в интернете.

1. Откройте: https://github.com
2. Нажмите **Sign up**.
3. Придумайте логин латиницей. **Важно**: этот логин попадёт в адрес вашего сайта (например, `https://ivan-petrov.github.io/...`). Поэтому выбирайте что-то нормальное — короткое, без цифр и подчёркиваний, не `kotik2008`.
4. Введите email и пароль.
5. Подтвердите email через ссылку из письма.

> 🔐 **Двухфакторная аутентификация.** Через какое-то время GitHub попросит её включить. Согласитесь — это не страшно. Установите на телефон приложение **Google Authenticator** или **Microsoft Authenticator** (бесплатно из App Store / Google Play), и GitHub проведёт через настройку.

---

## Шаг 4. Открываем вкладку Code

В окне приложения сверху есть три вкладки: **Chat**, **Cowork**, **Code**.

Нажмите на **Code**. Это и есть наш инструмент для создания сайтов.

### Тут возможны два сценария

**Если у вас Mac:** в большинстве случаев Code откроется сразу. Mac обычно уже умеет работать с Git «из коробки».

**Если у вас Windows ИЛИ если Mac выдал окно «Git is required»:**

Приложение покажет сообщение, что нужен **Git**, и даст ссылку на его установку.

#### Если Windows:

1. Прямо в этом сообщении нажмите ссылку — она ведёт на https://git-scm.com/downloads/win
2. Скачайте установщик Git.
3. Запустите его двойным кликом.
4. На всех экранах нажимайте **Next** — все настройки по умолчанию подходят.
5. В конце нажмите **Install**, затем **Finish**.
6. **Полностью закройте Claude Desktop** (правый клик на иконке в трее → Quit, или через Диспетчер задач).
7. Откройте Claude Desktop заново.
8. Вкладка Code теперь должна работать.

#### Если Mac:

Если приложение всё-таки попросило установить Git:

1. Откройте программу **Терминал** (Cmd+Space → напечатайте «Терминал» → откройте).
2. Скопируйте и вставьте туда команду:

```
xcode-select --install
```

3. Нажмите Enter. Появится окно — нажмите **Установить**.
4. Подождите окончания (5–10 минут).
5. Закройте и снова откройте Claude Desktop.

> 💡 Это **единственное** место в обоих гайдах, где может понадобиться терминал. Дальше всё через окно приложения.

---

## Шаг 5. Проверяем, что всё работает

1. В Claude Desktop откройте вкладку **Code**.
2. Внизу должна быть строка ввода (как в обычном чате).
3. Если строка есть и приложение не показывает ошибок — всё готово.

---

## Готово!

Проверьте по списку:

- [ ] Аккаунт на claude.ai создан, подписка Pro оформлена.
- [ ] Аккаунт на github.com создан, email подтверждён.
- [ ] Claude Desktop установлен и запускается.
- [ ] Вы вошли в Claude Desktop под своим аккаунтом.
- [ ] Вкладка **Code** в приложении открывается без ошибок про Git.

Если всё отмечено — переходите к **Гайду 2**.
