# Вайбкодинг для сотрудников без опыта

Учебная одностраничная веб-страница на русском языке для знакомства сотрудников
без технических навыков с концепцией **вайбкодинга** — создания цифровых решений
с помощью ИИ.

Цель — сформировать ощущение «я тоже так смогу» и дать конкретный первый шаг.

Собрано на **Vue 3 + Vite** с разбивкой по компонентам — чтобы любую секцию можно было
встроить в существующий проект.

---

## Быстрый старт

Нужен установленный [Node.js](https://nodejs.org/) **версии 18+** (рекомендуется LTS).

```bash
# 1. Установить зависимости
npm install

# 2. Запустить локальный dev-сервер (откроется http://localhost:5173)
npm run dev

# 3. Собрать production-версию в папку dist/
npm run build

# 4. (опционально) посмотреть собранную версию
npm run preview
```

После `npm run build` в папке `dist/` лежит статический сайт — его можно открыть
двойным кликом по `dist/index.html` или загрузить на любой хостинг (Vercel, Netlify,
GitLab Pages, обычный nginx).

```

├── package.json
├── vite.config.js
├── README.md
└── src/
    ├── main.js                 ← createApp(App).mount('#app')
    ├── App.vue                 ← корневой компонент, собирает секции
    ├── assets/
    │   └── main.css            ← глобальные стили и CSS-переменные
    ├── composables/
    │   └── useChecklist.js     ← reactive-чек-лист с автосохранением в localStorage
    └── components/
        ├── NavBar.vue
        ├── HeroSection.vue
        ├── PreparationSection.vue   ← «Раздел 0»: чек-лист подготовки
        ├── WhatIsSection.vue
        ├── WhatToBuildSection.vue
        ├── ToolsSection.vue
        ├── PromptFormulaSection.vue
        ├── StepsSection.vue          ← раскрывающиеся подшаги
        ├── MistakesSection.vue
        ├── PracticeSection.vue
        ├── ChecklistSection.vue      ← прогресс хранится в localStorage
        ├── FaqSection.vue            ← аккордеон с частыми вопросами
        ├── ResourcesSection.vue      ← полезные ссылки и сервисы
        ├── FinalSection.vue
        ├── AppFooter.vue
        ├── CalloutBox.vue            ← переиспользуемая плашка 💡/📌/⚠️
```

Каждый компонент — самостоятельная секция страницы. Тексты и данные (карточки,
шаги, ошибки) живут как массивы внутри `<script setup>` соответствующего компонента —
их легко редактировать, не разбираясь в шаблонах.

## Интеграция в существующий проект

### Вариант 1 — встроить как страницу

Откройте `npm run build` → положите содержимое `dist/` в нужное место своего сайта
(или на отдельный поддомен). Так же подойдёт для GitLab Pages.

### Вариант 2 — взять отдельный компонент

Любую секцию можно скопировать в свой Vue 3 проект:

```js
// допустим, у вас уже есть Vue-приложение
import StepsSection from './components/StepsSection.vue'
import './assets/main.css' // нужны общие CSS-переменные и базовые классы
```

> ⚠️ Стили лежат глобально в `src/assets/main.css` (CSS-переменные `--accent`,
> `--bg` и базовые классы `.container`, `.btn`, `.card`, `.grid`). При интеграции
> либо подключите этот файл, либо перенесите нужные блоки из него.

### Вариант 3 — через iframe

Если ваш основной проект на другом фреймворке (React, Angular, обычный сайт) —
самый быстрый способ: задеплоить эту страницу отдельно и встроить через
`<iframe src="…" />`.

## Что внутри страницы

- **Hero** — заголовок, подзаголовок, CTA
- **Подготовка (Раздел 0)** — интерактивный чек-лист «что нужно перед стартом»
- **Что такое вайбкодинг?** — простое объяснение + пример «плохо/хорошо»
- **Что можно создать?** — 6 карточек с типовыми идеями
- **Инструменты** — ChatGPT, Claude, Replit, Lovable, Cursor
- **Формула хорошего промпта** — 6 пунктов + готовый пример
- **7 шагов для старта** — раскрывающиеся блоки с подсказками
- **Частые ошибки новичков** — с примерами «как правильно»
- **Практика** — шаблон промпта с кнопкой «Скопировать»
- **Чек-лист готовности** — интерактивный, прогресс сохраняется в localStorage
- **FAQ** — аккордеон с 7 типичными вопросами
- **Ресурсы** — полезные сервисы для новичка (ИИ, сайты, дизайн, вдохновение)
- **Финальный CTA**

## Технологии

- **Vue 3** (Composition API, `<script setup>`)
- **Vite** для дев-сервера и сборки
- Чистый CSS с переменными — без UI-библиотек и препроцессоров
- Адаптивная вёрстка (брейкпоинт 860px)

---

## Дизайн

- Светлый фон, тёмный текст
- Акцент: фиолетово-синий градиент (`#6a5cff` → `#4a8bff`)
- Мягкие пастельные блоки, округлённые углы, аккуратные тени
- Дружелюбный корпоративный стиль

Цветовая палитра задана CSS-переменными в [`src/assets/main.css`](src/assets/main.css) —
меняется в одном месте.
